# JOUR405: Statistics for Journalists — Fall 2026

This is your personal repository for JOUR405 at the University of Maryland. You will use it to complete homework assignments, follow along with in-class activities, and build your final project. All of the work in this course uses **R** and **RStudio**. To get started, click the green "Use this template" button near the top right and choose "Create a new repository", then give it a relevant name like "jour405". Clone that repository to your computer using GitHub Desktop. Using your computer's Finder or File Explorer, double-click on the `jour405_fall26.Rproj` file to open RStudio.

## Repository Structure

It will help you to keep your files organized in the folders they are already in.

```
jour405_fall26/
├── activities/       <- In-class exercises we work through together
├── explainers/       <- Code walkthroughs for each activity
├── homework/         <- Graded assignments you complete on your own
├── project/          <- Your final project files
└── jour405_fall26.Rproj  <- Open this file in RStudio to start working
```

### `activities/`

These are R Markdown (`.Rmd`) files used during class. Each one walks through a statistical concept with real data — things like sampling, confidence intervals, hypothesis testing, correlation, regression and more. You will work on these, save them and push them to GitHub.

### `explainers/`

Code walkthroughs for each activity. These explain what the R code is doing in plain language — not the statistical concepts, but the mechanics of each function, argument, and pattern. Each file matches an activity by name (e.g., `CarThefts_Explainer.Rmd` goes with `CarThefts.Rmd`). Use these when you are stuck on what a piece of code does or want to review before doing homework.

### `homework/`

Numbered assignments that you will complete and push back to GitHub. Each file contains instructions, empty code blocks for your answers, and questions to respond to. Homework builds on what we cover in activities and readings.

### `project/`

Your final project lives here. See `suggested_projects.md` for example project ideas and scoping advice. You will use the statistical methods from class, such as regression, t-tests, correlation, z-scores, etc., to investigate a question using public data.

## Submitting Work

When you finish a homework assignment:

1. Save the `.Rmd` file.
2. Switch to GitHub Desktop to add, commit and push the file(s) you changed.
3. Submit the URL of that file on GitHub.com in ELMS.
